# SuperSimpleDev: Front-End Learning Journey

A collection of my work while learning front-end web development (HTML and CSS) through the courses by [SuperSimpleDev](https://supersimple.dev/courses) (Simon Bao). The projects range from beginner exercises to more advanced, real-world layouts.

## 📚 About

This repository documents my progress as I build a solid foundation in front-end development. Each lesson reinforces the concepts covered in the course and shows how my skills have grown over time.

## 🎯 What I'm Learning

- **HTML**: semantic structure, forms, links, images and accessibility basics
- **CSS**: selectors, the box model, typography, colours and spacing
- **Layout**: Flexbox, CSS Grid and positioning
- **Responsive design**: building layouts that work across screen sizes
- **Best practices**: clean, readable and maintainable code
